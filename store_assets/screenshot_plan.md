スクリーンショット計画（案）

最終更新: 2026-09-07

想定デバイス
- iOS iPhone: 6.7"（推奨）+ 6.1"
- iOS iPad: 13"（iPad Pro 13-inch シミュレータで撮影・ネイティブ対応時は必須）
- Android Phone: 縦長（9:16 前後、各辺 320–3840 px）。Play は最低 2 枚、宣伝向けは 4 枚以上・短辺 1080+ 推奨

撮影シーン（推奨 6〜8 枚・Pro ひらめきモード込み）

1) モード選択（サイコロ / カード / **ひらめき**が見える）
   - キャッチ例: 「シーンに合わせて遊び方を選べる」
   - **Pro オン状態**でマッシュアップ・ビンゴカードが見えること

2) 3Dサイコロ画面（テーマ決定）
   - キャッチ例: 「3Dサイコロで話題が決まる」

3) **マッシュアップ**（スロットが並んだプレイ画面）
   - キャッチ例: 「言葉を組み合わせてお題を作る」

4) **会話ビンゴ**（3×3 ボード）
   - キャッチ例: 「マスを埋めて会話を広げる」

5) 価値観カード（またはグループ / 1on1）
   - キャッチ例: 「価値観を共有して対話を深める」

6) 履歴 or プリセット
   - キャッチ例: 「セッション履歴を確認 / ワンタップで再開」

差し替え候補（枚数調整用）
- テーマ設定（ドラッグ&ドロップ）
- セッション設定（人数・タイマー）
- Pro ペイウォール（訴求用・任意）

撮影時の注意
- **debug で Pro をオン**してからひらめきモードを撮る（About → Pro（debug）→ Pro をオン）
- 画面内にプレースホルダ（空のリスト/無反応状態）が出ないようにする
- 端末内の通知や時刻は控えめな表示にする
- 文言は日本語版/英語版で別撮りするのが理想
- Android 保存先: `store_assets/screenshots/android/16x9/{ja,en}/`
- 旧セット（2026-03）はマッシュアップ・ビンゴ無し → **要撮り直し**

### 任意の追加撮影

Play 訴求を強めるなら次があるとよい:

- マッシュアップ **プレイ**（スロットが回った／止まった画面）
- ビンゴ **盤面**（3×3 or 5×5）
- 価値観カードのプレイ画面

```bash
ADB=~/Library/Android/sdk/platform-tools/adb
OUT=store_assets/screenshots/android/16x9/ja
# 電源+音量下で撮ったあと:
$ADB pull /sdcard/Pictures/Screenshots/Screenshot_19700228-XXXXXX.png "$OUT/"
```

（端末時刻が直っていれば通常の `Screenshot_YYYYMMDD-*.png`）
